---
name: pitch
description: Write a 2-minute hackathon pitch and demo script from what's actually built, then optionally role-play as a judge. Use near the end of the day when preparing to present.
---

1. Read `CLAUDE.md`, the code, and `demo/inputs.md` if it exists. Pitch only what actually works — never claim features that aren't built.
2. Write `demo/pitch.md` with a ~2-minute script (~260 spoken words), sectioned with timings:
   - **Hook (15s):** the problem, concretely, ideally a relatable person/scenario.
   - **Demo (60s):** exact clicks/inputs and what to say while it loads. Lead with the most impressive moment.
   - **How it works (20s):** one or two sentences, mention the interesting technical bit.
   - **Why it matters / what's next (20s):** tie to the sponsors where it's genuine (Wordsmith: legal AI; Skyscanner: travel).
   - **Close (5s):** team name + one memorable line.
3. Add a "who says what" split for 3 people, and a "if the demo breaks" line to say while switching to the backup video.
4. Then offer to act as a judge: ask 5 tough but fair questions (one at a time if the user agrees), e.g. "how is this different from just using ChatGPT?", "what happens when the model is wrong?", and give feedback on each answer.
